☁ Синхронизация

Состояние хранится в секретном gist на GitHub — он не виден в профиле и не индексируется, но доступ с любых устройств по ID. На устройстве, с которого отправляешь показания, нужен токен (fine-grained, единственное право «Gists: Read and write»); на остальных достаточно Gist ID — они работают в режиме только чтение, без токена.
